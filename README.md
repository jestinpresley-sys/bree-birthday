# Happy Birthday, Bree

A birthday site for Bree: photos, videos, a letter, and candles to blow out.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

- `photos/` – still images
- `videos/` – muted autoplay clips (`bree-solo.mp4` is kept for later use)
